## Project Description

Princess Ellis Contacts Address Book is a simple Android mobile application developed using Android Studio and Kotlin. The application allows users to view a list of contacts and select a contact to see their personal information.

This project demonstrates how to create multiple screens, design user interfaces using XML layouts, and navigate between activities in an Android application.

## Features

- Displays a contacts address book.
- Organizes contacts alphabetically.
- Provides buttons to view individual contact details.
- Displays each contact's name, address, phone number, and email address.
- Includes a contact profile icon.
- Uses a purple and light pink color theme.
- Allows users to navigate between the main screen and contact detail screens.

## How to Run the Application

1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize.
4. Start an Android emulator or connect an Android device.
5. Click the Run button.
6. Select View Details to open a contact's information.
